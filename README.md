# Nomad Chef

A chaotic couch co-op cooking game in the spirit of *Overcooked*, set in a Kazakh yurt kitchen.
One to four chefs chop, boil, fry, plate and serve Kazakh dishes against the clock, while
keeping the plates washed and the kitchen from burning down.

Built with **Unity 6 (6000.6.5f1)**, the Universal Render Pipeline and the new Input System.

## Play

1. Open the project in Unity 6000.6.5f1.
2. Open `Assets/Scenes/MainMenu.unity` and press Play.
3. Click inside the Game view so it receives keyboard input.

A round lasts 3 minutes. Serve orders before the customers lose patience; fast service earns tips,
expired orders cost points. Stars are awarded at 40, 100 and 160 points.

### Controls

| | Move | Pick up / put down | Use (chop, wash, spray) | Dash | Join |
|---|---|---|---|---|---|
| Player 1 (keyboard left) | WASD | Space | F | Left Shift | starts in the game |
| Player 2 (keyboard right) | Arrow keys | Enter | `/` | Right Shift | press Enter |
| Gamepads (up to 4 players) | Left stick / D-pad | A | X | B / Right trigger | press any button |

On the game-over screen: **Space / Enter / A** plays again, **Shift / B** returns to the menu.

## Gameplay

**Dishes**

| Dish | Ingredients | Points |
|---|---|---|
| Beshbarmak | boiled meat + boiled dough + sliced onion | 30 |
| Kuyrdak | fried meat + fried onion | 25 |
| Kespe | boiled dough + boiled meat | 20 |
| Et | boiled meat + sliced onion | 20 |

**Stations**

- **Ingredient crates**: meat, onion, dough.
- **Cutting board**: put an ingredient down and press *Use* once; the chef keeps chopping while standing there.
- **Kazan**: boils chopped meat and cut dough. Left too long, food burns, and burned food catches fire.
- **Frying pan**: fries chopped meat and sliced onion for kuyrdak.
- **Tabaq plates**: hold one of each ingredient. Plate food from counters, the board, or straight out of the kazan or pan.
- **Serving window (dastarkhan)**: serves a plate that matches an order; wrong plates are refused.
- **Dirty plates**: served plates come back dirty a few seconds later. The kitchen owns only four plates.
- **Sink**: drop dirty plates in, press *Use* once, and clean plates go back to the rack.
- **Fire**: spreads to neighbouring counters. Hold *Use* with the extinguisher to put it out.
- **Bin**: throws food away and empties plates; plates and tools can't be thrown away.

## Adding content

Most content is data; no code changes are needed.

- **New dish**: *Create > Nomad Chef > Dish Recipe*, set its ingredients, points and patience,
  then add it to **Menu** on `Managers/OrderManager` in the kitchen scene. Make sure its
  ingredients are listed under **Valid Ingredients** on the `Plate` prefab.
- **New cutting / cooking recipe**: *Create > Nomad Chef > Cutting Recipe* or *Cooking Recipe*,
  then add it to the **Recipes** list on the cutting board, kazan or pan prefab.
- **Tuning**: round length, star scores and penalties are on `Managers/GameManager`; order pace
  and tips on `Managers/OrderManager`; movement on the `Player` prefab; animation on its
  **Chef Animator** component.

## Art pipeline

Every model is generated by a Python script in `ArtSource/`, run with Blender 5.2 in background mode:

```bash
blender --background --factory-startup --python ArtSource/build_props.py
```

| Script | Models |
|---|---|
| `build_props.py` | counters, crate, hearth, kazan, pan, cutting board, knife, plates, sink, rack, bin, extinguisher |
| `build_food.py` | ingredients and their chopped, cooked and burned states |
| `build_chef.py` | the chef, as separate parts that Unity animates |
| `build_environment.py` | the yurt kitchen |
| `build_menu.py` | the main menu backdrop |

Each script exports FBX files to `Assets/Art/Models/` and saves a `.blend` copy in `ArtSource/`.
Blender material names map to Unity palette materials (`WoodLight` becomes `M_Art_WoodLight`),
so colours are tuned in Unity only. After adding a new material name in Blender, run
**Nomad Chef > Art > Apply Palette Materials** in Unity once.

## Audio

All sounds and both music tracks (dombyra, kobyz, dauylpaz and asatayak) are synthesized
placeholders. Replace any file in `Assets/Audio/` with a real recording of the same name and
the game picks it up.

## Git

Binary assets (`.blend`, `.fbx`, `.wav`, `.png`, …) are stored with **Git LFS**. Install Git LFS
before cloning, and use a remote that supports it.

`.mcp.json` (local Claude Code / Unity MCP configuration) is machine-specific and ignored.
The `com.coplaydev.unity-mcp` package is an editor-only bridge for AI tooling; the game does not use it.
